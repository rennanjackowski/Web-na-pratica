WEB NA PRÁTICA

Projeto da disciplina DFEW.08 - Desenvolvimento Front-End para Web (Universidade Positivo).
Autores: Paulo Geandre Pinto e Rennan Jackowski. Professor: Fabricio Olivo.

COMO ABRIR
1. Abra o arquivo index.html no navegador. O conteúdo local funciona sem internet e sem servidor; links externos precisam de conexão. Descompacte o ZIP inteiro antes de abrir.
2. Use o menu para visitar as dez páginas.
3. Teste os botões, o formulário, o áudio e o vídeo.
4. Diminua a janela para ver a versão de celular.

PASTAS
css/    estilos do site e Bootstrap
js/     JavaScript do site e Bootstrap
img/    imagens
video/  vídeo
audio/  áudio
doc/    documentação em Word

OBSERVAÇÕES
- O formulário de contato guarda as mensagens no navegador (localStorage).
- O link MDN do menu e os links do rodapé só abrem com internet.
- As páginas sobre.html e html.html usam apenas HTML, CSS e JavaScript puros.

- O menu usa classes do Bootstrap em oito páginas e código próprio em Sobre e HTML, com a mesma aparência.
- As mensagens são demonstrativas e não são enviadas a um servidor. A persistência depende das permissões do navegador.
