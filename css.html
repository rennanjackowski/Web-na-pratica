CSS

CSS define a aparência dos elementos HTML: cores, tamanhos e posições.

Três formas de aplicar CSS

1. CSS externo: este texto recebe a cor do arquivo css/estilos.css.

2. CSS incorporado: este texto é estilizado por uma tag style dentro da página.

3. CSS em linha (inline): este texto usa o atributo style no próprio elemento.

Seletores: tag, classe e id

O estilo pode ser aplicado a uma tag (como h2), a uma classe (como .caixa) ou a um id (como #exemplo-id).

Este parágrafo é estilizado pelo seletor de id #exemplo-id.
