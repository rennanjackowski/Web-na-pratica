HTML

HTML é a linguagem usada para organizar o conteúdo de uma página.

Elementos básicos

Uma página pode ter títulos, parágrafos, listas, imagens, links e tabelas. Cada um é criado por uma tag.

  • <h1> cria um título principal.
  • <p> cria um parágrafo.
  • <a> cria um link.
  • <img> mostra uma imagem.
  • <ul> e <li> criam listas.

O HTML define o conteúdo. O CSS modifica a aparência. O JavaScript cria as interações.

Estrutura semântica

Todas as páginas deste site seguem a mesma estrutura, com tags que descrevem o papel de cada parte:

<header>  cabeçalho com o menu
<main>    conteúdo principal
<section> bloco de conteúdo
<footer>  rodapé
