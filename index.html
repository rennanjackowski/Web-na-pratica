Web na Prática

Guia visual para quem está começando a criar páginas web com HTML, CSS, JavaScript e Bootstrap.

Bem-vindo!

O Web na Prática reúne dez páginas com exemplos reais de HTML, CSS, JavaScript e Bootstrap. Cada página explica um assunto e traz um exemplo para você testar.

Por onde começar?

HTML

Organiza textos, imagens, links e tabelas em uma página.

Abrir HTML

CSS

Define cores, tamanhos, espaços e a posição de cada elemento.

Abrir CSS

JavaScript

Cria ações com botões, campos e dados salvos no navegador.

Abrir JavaScript

Flexbox e Grid

Alinha blocos em linha e organiza galerias em colunas.

Abrir Flexbox

Áudio e vídeo

Reproduz arquivos de som e imagem com controles nativos.

Abrir Mídias

Contato

Formulário com validação que guarda as mensagens no navegador.

Abrir Contato

Trilha sugerida

  1. Leia a página HTML para entender a estrutura de uma página.
  2. Veja na página CSS como mudar a aparência.
  3. Teste os alinhamentos em Flexbox e a Galeria.
  4. Experimente os exemplos em JavaScript.
  5. Deixe uma mensagem na página de Contato.
