Sobre o projeto

Conheça o objetivo do site e a equipe que o desenvolveu.

Objetivo

Este site foi criado para a disciplina Desenvolvimento Front-End Para Web, da Universidade Positivo. Ele apresenta, de forma simples e prática, as tecnologias básicas usadas para criar páginas web.

Navegue pelas dez páginas, teste os botões, preencha o formulário e assista ao vídeo.

Equipe

  • Paulo Geandre Pinto — desenvolvimento compartilhado das páginas HTML, estilização com CSS e Bootstrap e programação em JavaScript.
  • Rennan Jackowski — desenvolvimento compartilhado das páginas HTML, estilização com CSS e Bootstrap e programação em JavaScript, além da organização e publicação no GitHub.

Professor: Fabricio Olivo.

Assuntos estudados

  • HTML e a estrutura das páginas.
  • CSS e a aparência dos elementos.
  • Bootstrap e o layout responsivo.
  • JavaScript e as interações com o usuário.

Esta página usa apenas HTML, CSS e JavaScript puros, sem Bootstrap.

Projeto da Disciplina Desenvolvimento Front-End para Web, Universidade Positivo.

Autores: Paulo Geandre Pinto e Rennan Jackowski. Professor: Fabricio Olivo.
