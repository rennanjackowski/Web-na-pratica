Sobre o projeto

Conheça o objetivo do site e a equipe que o desenvolveu.

Objetivo

Este site foi criado para a disciplina Desenvolvimento Front-End para Web (DFEW.08), da Universidade Positivo. Ele apresenta, de forma simples e prática, as tecnologias básicas usadas para criar páginas web.

Navegue pelas dez páginas, teste os botões, preencha o formulário e assista ao vídeo.

Equipe

  • Paulo Geandre Pinto — desenvolvimento do site e do software.
  • Rennan Jackowski — responsável pelo GitHub e pelos ajustes e revisões do projeto.

Professor: Fabricio Olivo.

Assuntos estudados

  • HTML e a estrutura das páginas.
  • CSS e a aparência dos elementos.
  • Bootstrap e o layout responsivo.
  • JavaScript e as interações com o usuário.

Esta página usa apenas HTML, CSS e JavaScript puros, sem Bootstrap.
